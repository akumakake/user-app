# User App — приложение для просмотра пользователей
SPA на React со списком пользователей и детальной карточкой выбранного пользователя.
# Возможности
•	Загрузка списка пользователей с REST API
•	Просмотр детальной информации о выбранном пользователе
•	Обработка состояний загрузки и ошибок
•	Повторный клик по активному пользователю не дублирует запрос
•	Адаптивная вёрстка: список слева, детали справа
# Технологии
•	React — библиотека для UI
•	Vite — сборка и dev-сервер
•	JavaScript (ES6+)
•	Fetch API — сетевые запросы
•	CSS Grid / Flexbox — раскладка
•	useEffect — работа с побочными эффектами
